# Quadratische Funktionen und Gleichungen – Übungsseite (Klasse 9)

Interaktive Übungsseite zur Vorbereitung auf eine Klassenarbeit: Grundlagen (Rechenregeln, Klammern, binomische Formeln, Umstellen), zehn Themenblöcke zu quadratischen Funktionen und Gleichungen, Probearbeit mit Zeitlimit, „Fehler finden“ und ein Merkblatt zum Ausdrucken.

- Reines HTML, CSS und JavaScript, keine Installation nötig. Läuft auch offline per Doppelklick auf `index.html`.
- Formelsatz mit [KaTeX](https://katex.org) (MIT-Lizenz, liegt in `lib/katex`).
- Fortschritt wird nur im Browser gespeichert (localStorage).

Tests (Node):

```
node tests/kern.test.js
node tests/generatoren.test.js 500
```
